# 阶段三最小使用闭环

本子步骤接通「填 key → 校验连接 → 选择比例 → 手动开始」，不代表阶段三整体或安装版已完成。平台保持 Windows 11 x64、WinForms、.NET 10，自包含安装包留阶段四。

- [x] 输入 key；默认当前 Windows 用户 DPAPI 保存，也可仅本次使用。
- [x] 固定官方地址；显式 GET 模型校验，改 key 后旧校验失效。
- [x] 内置生成约 34 万字符技术文本，异步准备，每轮复用；最多 3 并发、1024 输出上限。
- [x] 通过持久运行入口开始、暂停、继续、停止；显示确认用量、在途和未知数量。
- [x] 重开读取运行证据，不自动请求；未知用量需明确核查确认。
- [x] 退出等待请求收尾；Release、275项mock行为测试及完整面板资源检查通过。
- [ ] 新面板实际窗口操作（未验证，桌面控制已关闭）；真实账户连接、token估计与积分效果验证留后续。

原脚本的约 18 万输入 tokens 是估算。本版内部先按 20 万输入 tokens + 1024 输出预留；不是 tokenizer 结果，也不是积分硬上限。模型缺少上下文/输出能力或能力不足时拒绝开始，累计以 API usage 为准；实际 usage 超出预留则触发已有保护。真实账户校准留获准真实验证，不要求用户填写 token 估计。

普通启动使用真实 HTTP，但初始化、保存和恢复确认均不联网。连接校验只 GET 模型，不能证明剩余积分或未来返赠；点击开始才发送消耗请求。开发命令与资源测量显式使用 mock。真实与模拟数据目录、配置/DPAPI文件隔离，不读取或迁移旧脚本凭据。

本轮暂不接周期计划开关、托盘、历史导出和美化。小时配置仍保存，计划保持关闭；关闭窗口当前执行退出收尾。测试不会自动使用真实 key 跑完整目标。

## 使用顺序与当前验证

普通启动后输入自己的key，选择保存方式，点击“保存配置与凭据选择”（可选），再点“校验连接并读取模型”。选择活动Flash-Lite与比例，点击“开始本轮”；0%禁用开始。首次只校验模型，不自动试跑。保存不会开始运行，周期输入目前只保存配置。

运行中“暂停”只暂停新增，等待在途结果；“继续”恢复普通暂停。“停止本轮”先停止新增并等待在途，超时或退出取消不能证明服务端没有消耗。限流等待核查时先停止收尾，再查看官方账户，勾选已核查并确认记录。记录保存失败或损坏不能通过普通确认绕过。

恢复确认与连接校验不是额度确认。下一次启动不会续跑旧目标或自动启用计划。仅本次使用不写新密文，旧密文保留但下次不读取；取消选择不等于删除过去保存的key。

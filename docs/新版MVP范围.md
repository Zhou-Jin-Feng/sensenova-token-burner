# 新版 MVP 权威范围

生效：2026-10-06。用户本轮明确指定；替代旧方案中“默认单 key、多 key 后续再做”的决定。历史验证报告保留为历史，不代表新版已验收。

## 交付目标

轻量 Windows 11 x64 WinForms 面板，同一个桌面进程管理多个 SenseNova API key。安装后只必填 API key，可选备注（如key-1、key-2），作为列表显示名称；未填自动生成key-N，随配置保存重开。固定 `https://token.sensenova.cn/v1`，复用活动模型、DPAPI、比例控件、运行引擎与保护。保存配置不自动开始，重开不自动消耗。

## 必须实现

1. 多 key 按当前 Windows 用户加密保存，界面遮蔽；普通设置、日志、运行记录不保存明文。升级保留已有 key、配置、历史；迁移保留旧文件。
2. 每个 key 为独立任务，有目标比例/自定义 token 目标、启用状态、间隔（默认 5 小时）和下次计划时间。单独运行、暂停、继续、停止和计划启停；运行全部、暂停全部、停止全部。
3. 同一进程内任务并行，全应用共享请求并发上限（默认且最高 3），相同 key 不重叠。一个任务错误不影响其他任务，逐项显示结果。
4. 保留 0–95% 和四档预设；支持单任务自定义目标量。1.2 亿 tokens / 约 58,000 点为特定条件的经验值。超过提示可能扣通用积分，低于提示可能未用满专属积分；任何目标均不能保证绝对安全或精确返赠。
5. 每行显示确认 tokens、当前目标、状态、错误/待核查和下次时间；运行全部显示整体进度与完成汇总。主面板左下角完成提示；隐藏到托盘也通知。
6. 每任务保存目标、确认用量、检查点和在途预留。重开提示未完成任务，显式“继续剩余目标”沿用确认进度；未知结果先要求核查，不自动重发。不声称恢复服务端的同一请求。
7. 5 小时仅为计划间隔，额度为滚动窗口，不称整点重置。多 key 不等于多份积分池；可归同一额度组，运行全部前展示组目标合计与风险提示。未归组也不推断独立额度。
8. 用现有原生控件调整布局、间距、层级与提示，不引入重量 UI 框架、每 key 独立程序或后台 Web 服务。

## 必要验收

- 至少两个模拟 key 保存重开，检查 DPAPI 和脱敏；旧配置/key/历史兼容保留。
- 单独运行与运行全部并行、共享在途上限；单独/全部控制、目标和计划互不串用、错误隔离和同 key 互斥。
- 模拟中断后沿用确认进度；未知请求不自动重发，核查确认不发请求。
- 完成提示、汇总与托盘通知入口。
- 最大支持并发只做一次代表性资源测量。

现有测试保留为基线，仅增加新行为必要验证；不重复 5 小时等待、长模拟、1.2 亿真实消耗或无关退出诊断。真实 key 与实际消耗另需用户明确授权。本轮仅模拟数据。

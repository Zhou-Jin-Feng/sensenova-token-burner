# 资源基线测量

日期：2026-10-05。已按确认的路线将正式源码迁移到 WinForms，复用现有核心、API 和配置模块；WPF 与独立原型数据保留为历史对照。测量未读取真实 API key，没有网络请求或真实积分消耗。

## 方法与范围

同机 Windows 11 x64（Build 26300）、20 个逻辑处理器、.NET 10.0.12，使用 Release 构建和实际打开的窗口。完整场景为预热 10 秒、待机 120 秒、串行模拟调用 60 秒；外部 PowerShell 每秒采样全部同路径应用进程，不计入 SDK、测试工具或采样脚本。

正式 WinForms 面板提供服务/模型、比例滑条及四档预设、小时配置、Windows 用户加密测试凭据、保存、单次模拟调用、取消和退出；复用现有 Core、Infrastructure、视图模型与资源测量流程。原型曾暂存于忽略的 `.local/prototypes/winforms/`，正式入口与控件现已纳入 Desktop 项目，不依赖该临时目录。

测量负载通过现有模型读取和单次模拟命令执行，每次 usage 为 128 输入 + 8 输出 = 136 tokens；模拟网络延迟 80ms，请求结束后异步等待 100ms，串行执行，没有等待忙循环。待机期间无请求，正常完成后应用自行退出。普通启动不会启用这个开发测量入口。

指标：工作集为应用当前驻留的内存，包含共享映射；私有内存统计私有分配，不等于当前驻留量。CPU 按 CPU 秒差 / 实际采样秒数 / 逻辑处理器数换算为整机百分比；场景交界样本不计入 CPU 平均值。场景内存峰值取每秒采样最大值，另记录进程生命周期峰值；一秒采样可能漏掉很短的瞬时峰值。

未调用强制 GC、裁剪工作集或结束其他应用。不同时间启动会受到系统回收和缓存影响，以下结果只代表当前机器和场景。

## 完整基线

CPU 口径更正：复核发现旧采样脚本的 `[Math]::Max(0, doubleDelta)` 在 PowerShell 选择了 `Int32` 重载，将小数 CPU 秒差舍入成整数。因此以下旧 Schema 1 完整/短测报告的 CPU 列不用于验收，内存指标保持有效。当前脚本使用显式 `double` 重载，计算接缝的回归检查在旧逻辑下失败、修正后通过（4 个精度场景、3 个非法条件）；修正后的 Schema 2 正式完整复测已通过，真实样本含 136 个非整数 CPU 秒增量。CPU 占比为整机百分比，读数 0 也不等于绝对没有 CPU 消耗。

最新正式 WinForms（Schema 2）：待机工作集平均 68.06 MiB、峰值 69.36 MiB，私有内存峰值 20.09 MiB，CPU 平均 0.251%、每秒样本最大 1.074%；模拟请求工作集平均 84.61 MiB、峰值 87.45 MiB，私有内存峰值 31.70 MiB，CPU 平均 0.766%、样本最大 2.078%。119 个待机样本、59 个负载样本，CPU 覆盖分别 119.30 / 58.62 秒。1 个应用进程，277 次成功模拟请求 / 37,672 虚拟 tokens，退出码 0，窗口标题已观察到，未发现 WPF 渲染或 GPU 驱动模块。

本轮待机平均 CPU ≤1%、待机工作集 ≤100 MiB、模拟运行工作集 ≤150 MiB 均满足。CPU 目标针对场景平均值，每秒短时峰值另行记录；本轮结果不能证明完整目标、大输入或长期托盘场景已经达标。

历史 WPF：待机工作集平均 28.68 MiB、峰值 116.63 MiB，私有内存峰值 86.50 MiB；模拟调用工作集平均 82.91 MiB、峰值 88.42 MiB，私有内存峰值 91.75 MiB。119 个待机样本、60 个负载样本；单个应用进程，298 次成功模拟请求 / 40,528 虚拟 tokens，退出码 0。

历史 WinForms 原型：待机工作集平均 57.03 MiB、峰值 57.34 MiB，私有内存峰值 14.29 MiB；模拟调用工作集平均 74.76 MiB、峰值 77.39 MiB，私有内存峰值 26.43 MiB。119 个待机样本、60 个负载样本；单个应用进程，252 次成功模拟请求 / 34,272 虚拟 tokens，退出码 0。窗口标题已观察到，采样未发现 WPF 渲染模块或 NVIDIA/Intel/AMD 驱动模块。

按当前待机工作集 ≤100 MiB、运行工作集 ≤150 MiB 的目标，历史 WPF 待机内存未达标，WinForms 原型和正式程序首次复测的内存达标。原型待机峰值比历史 WPF 约低 51%，正式首次复测约低 40%；不是跨机器保证，也不是最终产品验收。各轮采用相同时间和模拟流程，但成功请求数不同，不作为严格等吞吐性能比较。

WPF 工作集在待机后期被系统回收，导致场景平均值低于峰值；这不能证明正常占用上限只有十几 MiB。普通启动（无诊断入口）预热 10 秒后待机 20 秒，工作集平均约 108.05 MiB、峰值 108.06 MiB，私有内存峰值 69.02 MiB，说明诊断驱动不是主要原因。

历史 WinForms 原型普通启动（无诊断入口）的窗口在可访问性读取后另采样 20 秒：工作集平均 79.85 MiB、采样峰值 79.89 MiB、进程生命周期峰值 80.17 MiB，私有内存峰值 27.30 MiB、CPU 平均 0%（本次补采样直接求差，无整数夹取）。这是已经打开的窗口短采样，前置状态不同于完整基线，未强制回收；固定原型基线的 57 MiB 不代表普通使用始终保持该数字。当前待机内存预期为约 60～80 MiB，仍需跨机器和长期使用验证。

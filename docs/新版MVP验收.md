# 新版多 key MVP 验收

日期：2026-10-06。权威需求为[新版MVP范围](新版MVP范围.md)，本轮仅模拟key和进程内mock，不读真实凭据、不发真实HTTP，不跑5小时等待或1.2亿真实消耗。

## 实现与必要验证

| 范围 | 证据与结果 |
| --- | --- |
| 多key/备注/DPAPI | 两个模拟key保存重开，key-1/key-2备注与独立目标/比例/间隔/启用保持；配置、密文和记录均无明文，重复key拒绝 |
| 旧资料兼容 | 沿用settings、密文、run-state路径，原文件字节不变；新增tasks索引，身份字段缺失阻断且保留原文件 |
| 并行与共享上限 | 跨key同时执行峰值3；两任务确认100/200虚拟tokens，不串目标；排队暂停/停止不产生未知预留 |
| 单独/全部控制 | 单独开始暂停、另一key继续；全部暂停/继续/停止、重复启动拒绝；运行全部等待已活动任务 |
| 计划与错误隔离 | 独立2.5h/5h下次时间用可控时钟验证；保存/重开零请求、保留计划提示但不开启；一个认证失败或密文损坏不停止有效任务 |
| 继续剩余目标 | 中断累计40→100，而非重新跑100；核查前及确认本身零请求；旧预留可提升到安全估计，原未知检查点归档保留 |
| 额度组/风险 | 运行全部预览组目标合计；说明滚动窗口、共享池和经验风险；自定义目标可超过比例档上限，提示可能扣通用积分 |
| 控件/通知 | 正式WinForms控件事件验证遮蔽、备注列表、跨key按钮；完成写左下角，隐藏调用NotifyIcon，实际弹出受Windows设置影响 |
| 配置竞态 | 计划在同一锁内只更新计划字段，不覆盖刚降低的目标、间隔和启用 |

新增MultiTaskMvpTests共16项，与受影响预算、引擎、保护、恢复、调度基线共134项通过、0跳过（约2.33秒）。原299项保留，未重复全量。Release构建0警告/0错误。独立代码复查PASS WITH NOTES，发现的费用与数据保护问题已修正并复核。

## 一次代表性资源采样

正式多任务窗体、同进程3虚拟key，共用34万字符生产输入、DPAPI和JSON检查点，mock每请求180ms。每200ms采样，负载约6秒，随后显式停止全部并正常退出，不强制GC。

- 全应用上限3，实测最多3在途，进程数1。
- 峰值工作集107.11MiB，低于既有运行目标150MiB；本机CPU平均约3.09%（按逻辑处理器数归一化）。这不是待机CPU验收。
- 90笔mock HTTP：3模型查询、87 completion；确认14,790,696虚拟tokens，最终在途0/未知0/退出0。
- 短样本仅代表本机mock最大支持并发，不推断真实账户、无限key规模或长期稳定性；不重复采样。

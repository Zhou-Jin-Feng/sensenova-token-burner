# 基础架构与开发

当前范围：Windows 11 x64、.NET 10、WinForms 模拟面板。已从 WPF 迁移，复用配置保存、DPAPI 虚拟凭据、模型读取与短请求 usage 解析；真实 API、运行引擎、调度和托盘尚待后续步骤，当前窗口关闭取消操作并退出。


| 项目 | 当前职责与依赖 |
| --- | --- |
| Core | 经验比例校准、配置校验、存储/API 接口、模型与 usage 类型；不依赖界面框架或 Windows 凭据能力 |
| Infrastructure | 固定官方地址、HTTP 协议适配器、终端 mock、原子文件保存与 Windows DPAPI；依赖 Core |
| Desktop | `Program` 原生入口、`MainForm` WinForms 控件、既有视图模型、配置/mock 操作和关闭取消；依赖 Core 与 Infrastructure |
| Tests | 使用 MSTest 验证比例、存储、HTTP 协议和视图模型流程；不属于最终桌面运行依赖 |

三个源码项目编译为同一桌面进程加载的程序集，项目数不会新增后台服务。基础设施新增微软 `System.Security.Cryptography.ProtectedData/10.0.12` 包，用于 Windows DPAPI；没有浏览器运行层或独立服务。依赖锁文件保存精确还原结果；新增或升级依赖时复查锁文件。

Desktop 和 Tests 使用 `UseWindowsForms`，原 WPF App/Window/XAML 入口已移除；正式源码不依赖临时 WinForms 原型。保留既有 `MainWindowViewModel` 名称与接口，避免界面迁移引入行为改写；`MainForm` 同步控件状态时抑制输入事件回写，防止配置恢复或模型重绑触发递归。迁移没有新增 NuGet 依赖，锁文件保持原样。

## 规则与接口

`ConsumptionPolicy.GetTargetTokens(int percentage)` 接受 0～95 的整数比例，按已确认校准表分段插值；超出范围抛出 `ArgumentOutOfRangeException`，0 返回 0。它只计算 token 目标，不查询或计算官方积分，也不会发出请求。

校准表为 0/25/50/75/95% → 0/30000000/60000000/90000000/120000000 tokens。`MainWindowViewModel` 通过该接口更新目标与绑定通知，非法选择不会覆盖上一有效选择。预设命令仅接受四个已确认档位。

比例、正数小时间隔、模型 ID 和凭据保存选项可保存为 schema 1 配置，不保存 key。选择“仅本次使用”时不写新凭据、不加载历史密文；已有密文保留，不自动删除。当前只验证内置虚拟 key，正式版 key 输入留到后续步骤。

### 存储与启动

`IUserSettingsStore` 与 `ICredentialStore` 分开。文件读取上限为 64 KiB；写入使用同目录唯一临时文件，成功后覆盖目标文件，取消时保留此前内容并清理本次临时文件。损坏 JSON、未知 schema/字段、越界配置和损坏密文安全报错，不回显原始文件数据。

开发脚本使用 `.local/mock-profile/`；直接启动程序使用 `%LOCALAPPDATA%/SenseNova.TokenBurner/Demo/`，可由进程环境变量 `SENSENOVA_MOCK_PROFILE` 指定测试目录。文件名固定为 `mock-settings.json` 与 `mock-credential.dat`，避免复用真实产品资料。DPAPI 使用 `CurrentUser`，临时明文字节在 finally 中清零；这不能隔离同一 Windows 用户权限下的其他程序。

打开窗口仅恢复配置与已保存的测试凭据，不读取模型、不发消耗请求、不启动调度。异步操作互斥；取消只作用于当前操作，关闭窗口取消并等待操作结束，再退出进程。`FormClosing` 首次取消关闭并等待清理，用 `BeginInvoke` 排队执行最终 `Close`，避免同步清理完成时事件重入；退出后注销视图模型事件并释放面板自建字体。模拟配置 schema、文件名和默认目录保持兼容。

### HTTP 与模拟模式

`ISenseNovaClient` 提供模型读取和短请求探针。`SenseNovaHttpClient` 使用固定官方地址，GET `models`、POST `chat/completions`，每请求带 Bearer Header。探针 `stream=false`、`max_tokens=32`；不是完整用量引擎。模型读取解析 `id/context_length/max_output_length`，当前仅确切 Flash-Lite ID 标注返赠资格，其余模型不能执行返赠探针。

成功 usage 必须包含非负整数 `prompt_tokens/completion_tokens/total_tokens`，合计等于输入加输出；缺失、负数、不一致、溢出、坏 JSON 或超过 1 MiB 的响应不能记为成功用量。401/403 为认证失败，429 为速率或额度受限（不判定永久耗尽），5xx 为暂时故障；错误提示不回显服务端正文或凭据。当前不自动重试，退避与预算控制属于阶段 2。

应用启动始终注入 `MockSenseNovaHandler`，这是没有网络链路的终端 HTTP 处理器，无监听端口和额外进程；与正式适配器共用请求/解析路径。只接受内置虚拟 key，返回两个模拟模型和 `128 + 8 = 136` 用量，也提供认证/429/503/缺失 usage/坏 JSON 测试场景。模型能力数字为模拟数据，不是当前账户查询结果。面板 0% 不发消耗请求；非零比例也只模拟一次，不执行完整 token 目标。

协议依据：[SenseNova 官方文档](https://platform.sensenova.cn/docs) 的模型列表与 Chat Completions 章节（2026-10-05 核查）；DPAPI 依据：[Microsoft 数据保护说明](https://learn.microsoft.com/en-us/dotnet/standard/security/how-to-use-data-protection)。真实调用需单独明确凭据与消耗授权。

## 开发命令

先按 README 准备 SDK 10.0.401，在项目根目录使用 PowerShell：

```powershell
& .\scripts\dev.ps1 restore
& .\scripts\dev.ps1 build
& .\scripts\dev.ps1 test
& .\scripts\dev.ps1 run
```

默认使用 Release，可传 `-Configuration Debug`。restore 默认使用仓库锁文件的 locked mode；新增或升级依赖时执行 `& .\scripts\dev.ps1 restore -UpdateLockFiles`，复查锁文件后再普通 restore。build/test/run 使用已有还原或构建结果；修改源码后先重新 build，再 test/run。测试采用 .NET 10 的 Microsoft.Testing.Platform，global.json 指定测试运行器。MSTest SDK 固定为 4.4.1，官方说明见 [MSTest SDK](https://github.com/microsoft/testfx/blob/main/src/Package/MSTest.Sdk/README.md)。

脚本优先使用项目内 SDK，否则查找 PATH 中的 dotnet，并核查固定版本；本次调用临时设置 DOTNET_ROOT、关闭 CLI 遥测/证书生成/全局工具 PATH 添加，将 CLI 与 NuGet 缓存置于 .local。结束后恢复调用前的进程环境变量，不改持久 PATH。

可运行 `& .\scripts\verify-dev-environment.ps1` 检查环境恢复；它通过实际 dev.ps1 info 调用，分别验证原变量不存在、有值、空字符串的情况，并核查工作目录恢复。

构建输出、缓存、日志和测试结果均不进入 Git。当前没有安装包；开发运行命令不能替代无 SDK 环境的安装验收。

## 验证边界

- 自动测试覆盖比例校准/边界、配置/DPAPI 往返与坏数据、取消不覆盖文件、官方请求结构、错误分类/脱敏、usage 校验、超时/取消、0%/未知模型无消耗、重开无请求、仅本次凭据、操作互斥和关闭等待。
- 正式 WinForms 界面需实际操作，确认布局、滑条/预设、模型、小时配置保存重开、虚拟凭据恢复、0% 禁用和关闭；该检查已选择延后，自动测试和资源驱动不能代替。
- 资源驱动只有显式 `--resource-baseline` 才启用；参数、取消、失败不可记完成、136 usage/成功计数等已有行为测试。外部 `measure-resources.ps1` 每秒采样应用进程，独立虚拟 profile，默认 10 秒预热 + 120 秒待机 + 60 秒串行短请求；不改调用者环境、不结束既有进程、不裁剪工作集。普通启动无自动测量负载。
- 正式 WinForms 窗口基线：待机峰值 69.36 MiB、平均 CPU 0.251%；模拟峰值 87.45 MiB、平均 CPU 0.766%，本机当前场景达标。旧采样整数舍入缺陷已修复，`verify-resource-sampling.ps1` 验证 4 个精度/3 个非法条件；Schema 2 真实样本确认非整数 CPU 秒增量。历史 Schema 1 CPU 列不用于验收，历史内存保持有效；托盘、大输入和真实引擎尚未验证，详见 [资源报告](资源基线测量.md)。
- 真实 API、官方余额/返赠到账、完整目标运行、调度、托盘、跨 Windows 用户的 DPAPI 隔离和安装包未验证。取消和凭据加密目前只以虚拟 key 验证。

2026-10-05 最新验证：正式 WinForms Release 构建 0 警告/0 错误，78 项测试全部通过（0 跳过）、locked restore 通过；CPU 采样精度检查与正式完整基线通过，277 次成功模拟请求 / 37,672 虚拟 tokens，退出码 0，未观察到 WPF 渲染模块。此前实际 WPF 窗口完成模型/136 usage、50% → 6000 万、2.5 小时保存、0% 禁用、关闭重开恢复与正常退出；这些是历史界面结果。正式 WinForms 的实际点击/视觉验收待补，阶段 1 闸门和正式产品验收尚未通过。

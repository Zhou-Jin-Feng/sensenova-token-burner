## 规则与接口

`ConsumptionPolicy.GetTargetTokens(int percentage)` 接受 0～95 的整数比例，按已确认校准表分段插值；超出范围抛出 `ArgumentOutOfRangeException`，0 返回 0。它只计算 token 目标，不查询或计算官方积分，也不会发出请求。

校准表为 0/25/50/75/95% → 0/30000000/60000000/90000000/120000000 tokens。`MainWindowViewModel` 通过该接口更新目标与绑定通知，非法选择不会覆盖上一有效选择。预设命令仅接受四个已确认档位。

比例、正数小时间隔、模型 ID 和凭据保存选项保存为 schema 2 配置，兼容 schema 1，不保存 key；读取旧版不重写文件，下次显式保存才升级。选择“仅本次使用”时不写新凭据、不加载历史密文；已有密文保留，不自动删除。key 输入已接通，自动测试只使用虚拟凭据，真实 API 尚未验收。

### 存储与启动

`IUserSettingsStore` 与 `ICredentialStore` 分开。文件读取上限为 64 KiB；写入使用同目录唯一临时文件，成功后覆盖目标文件，取消时保留此前内容并清理本次临时文件。损坏 JSON、未知 schema/字段、越界配置和损坏密文安全报错，不回显原始文件数据。

运行记录替换对 Windows 错误5/32/33提供最多10×50ms异步等待，处理短暂读锁；临时文件只写一次，持续失败仍阻断新增请求，取消保留旧记录。只有 JsonRunStateStore 启用等待，普通配置/DPAPI行为保持兼容。LocalStorageException 仅可附加系统错误编号，不保留原始路径/正文或异常对象。

普通启动使用真实 HTTP 与 `%LOCALAPPDATA%/SenseNova.TokenBurner/User/`，文件为 `settings.json`、`api-key.dat` 和 `run-state.json`。开发脚本使用 `.local/mock-profile/`；`--mock` 或进程变量 `SENSENOVA_MOCK_PROFILE` 显式启用mock，默认 `Demo/`，保留 `mock-settings.json` 与 `mock-credential.dat`。User/Mock的DPAPI熵独立，模拟旧文件兼容，不读取/迁移旧脚本凭据。DPAPI 使用 `CurrentUser`，临时明文字节在 finally 中清零；这不能隔离同一 Windows 用户权限下的其他程序。

打开窗口仅恢复配置与已保存的凭据，不读取模型、不发消耗请求、不启动调度。异步操作互斥；取消只作用于当前操作。标题栏关闭与最小化隐藏当前窗体，已启用计划和本轮继续；隐藏通知仅同步托盘，恢复全量同步控件。明确“退出”关闭计划并等待清理，`FormClosing`首次取消关闭，用`BeginInvoke`排队执行最终`Close`，避免同步清理完成时事件重入；FormClosed才取消诊断生命周期。释放VM事件、NotifyIcon、菜单及自建字体，没有新增服务或托盘轮询，见 [托盘报告](托盘与退出.md)。模拟配置schema、文件名和默认目录保持兼容。

Desktop 创建窗口前取得当前 Windows 用户固定路径的实例锁，遗留文件不会阻止再开。底层 PersistentRunSession 初始化不请求；原子 run-state.json 保存计划意图、本轮、20条历史、请求前预留和结算结果，文件上限64KiB。重开须确认、未知用量须核查，确认不运行；写失败阻断新增和未来计划。面板已统一调用这个运行入口；同一会话不因改key重新创建journal以绕过写失败，详见 [运行恢复](运行记录与人工恢复.md)。

### HTTP 与模拟模式

`ISenseNovaClient` 提供模型读取和短请求探针。`SenseNovaHttpClient` 使用固定官方地址，GET `models`、POST `chat/completions`，每请求带 Bearer Header。探针 `stream=false`、`max_tokens=32`；不是完整用量引擎。模型读取解析 `id/context_length/max_output_length`，当前仅确切 Flash-Lite ID 标注返赠资格，其余模型不能执行返赠探针。

完整请求 `CompleteAsync` 按同一不可变 CompletionRequest 对象复用一次 UTF-8 编码，用弱键和并发 Lazy 防止重复编码，独立请求/Header不共享凭据或响应；新请求对象不会复用旧正文。当前严格限定确切活动模型，后续若扩展多模型须同时调整缓存键。中文允许直接UTF-8，仍保持JSON敏感字符转义。mock直接从UTF-8流解析；模拟终端的分配节省不等同真实网络服务成本。

成功 usage 必须包含非负整数 `prompt_tokens/completion_tokens/total_tokens`，合计等于输入加输出；缺失、负数、不一致、溢出、坏 JSON 或超过 1 MiB 的响应不能记为成功用量。401/403 为认证失败，429 为速率或额度受限（不判定永久耗尽），5xx 为暂时故障；错误提示不回显正文或凭据。适配器保留安全执行状态/有界 Retry-After 提示；429 和送达不明的消耗请求不自动重试。引擎仅对可信 NotSent 暂时故障提供有限退避，已通过请求替身验证。

开发与资源模式注入 `MockSenseNovaHandler`，该mock是没有网络链路的终端 HTTP 处理器，无监听端口和额外进程；普通启动使用禁止自动重定向的真实HTTP处理器。两者与正式适配器共用请求/解析路径。只接受内置虚拟 key，返回两个模拟模型和 `128 + 8 = 136` 用量，也提供认证/429/503/缺失 usage/坏 JSON 测试场景。模型能力数字为模拟数据，不是当前账户查询结果。面板 0% 不发消耗请求；显式“开始本轮”按完整目标运行，短探针仅在mock中保留；真实模式不通过探针偷偷产生消耗。

协议依据：[SenseNova 官方文档](https://platform.sensenova.cn/docs) 的模型列表与 Chat Completions 章节（2026-10-05 核查）；DPAPI 依据：[Microsoft 数据保护说明](https://learn.microsoft.com/en-us/dotnet/standard/security/how-to-use-data-protection)。真实调用需单独明确凭据与消耗授权。

### 单轮 mock 引擎

Core 的 `RunParameters`、`IRunRequestExecutor`、`RunSnapshot` 和 `SingleRunEngine` 支持显式启动、0% 零请求、最多 3 在途、暂停/继续及收尾互斥。快照分开确认 usage、在途预留、未知计数；近目标降 1、预算不足提前结束。有效 usage 超预留时记录真实值，停止新增并收尾其余结果。取消停止等待不释放互斥，暂停异步等待。

Infrastructure 的 `MockRunRequestExecutor` 默认 50 ms 返回 136 虚拟 tokens，生命周期测试用可控替身。`CompletionRunExecutor` 连接完整 HTTP，要求有效估计/预留与模型/上下文预检，复用不可变输入。保护默认请求 2 分钟、停止宽限 15 秒、429 核查、人工确认和有界退避；未结束请求不释放互斥。RunScheduler 按 UTC 锚点实现周期、错过不补跑和保护立即关闭，不取消禁用时当前轮。PersistentRunSession 提供持久入口，发前/结算/最终检查点保护并保留跨重启证据；依赖未改，完整mock资源已验证，面板持久运行已接入，真实积分及新界面点击仍待验收。见 [单轮运行引擎](单轮运行引擎.md)、[异常保护](异常保护与恢复边界.md)、[周期调度](周期调度与时间规则.md)、[运行恢复](运行记录与人工恢复.md)。

## 开发命令

先按 README 准备 SDK 10.0.401，在项目根目录使用 PowerShell：

```powershell
& .\scripts\dev.ps1 restore
& .\scripts\dev.ps1 build
& .\scripts\dev.ps1 test
& .\scripts\dev.ps1 run
```

默认使用 Release，可传 `-Configuration Debug`。restore 默认使用仓库锁文件的 locked mode；新增或升级依赖时执行 `& .\scripts\dev.ps1 restore -UpdateLockFiles`，复查锁文件后再普通 restore。build/test/run 使用已有还原或构建结果；修改源码后先重新 build，再 test/run。测试采用 .NET 10 的 Microsoft.Testing.Platform，global.json 指定测试运行器。MSTest SDK 固定为 4.4.1，官方说明见 [MSTest SDK](https://github.com/microsoft/testfx/blob/main/src/Package/MSTest.Sdk/README.md)。

脚本优先使用项目内 SDK，否则查找 PATH 中的 dotnet，并核查固定版本；本次调用临时设置 DOTNET_ROOT、关闭 CLI 遥测/证书生成/全局工具 PATH 添加，将 CLI 与 NuGet 缓存置于 .local。结束后恢复调用前的进程环境变量，不改持久 PATH。

可运行 `& .\scripts\verify-dev-environment.ps1` 检查环境恢复；它通过实际 dev.ps1 info 调用，分别验证原变量不存在、有值、空字符串的情况，并核查工作目录恢复。

构建输出、缓存、日志和测试结果均不进入Git。当前已生成本地自包含预览安装包，隔离静默安装/卸载与入口加载通过；完整窗口使用及无SDK新系统仍未确认，见 [安装包报告](Windows安装包.md)。开发运行命令不能替代安装验收。

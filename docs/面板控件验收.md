日期：2026-10-06。本报告记录原276测试基线的key、模型、比例、手动运行、恢复和退出。后续计划基线292测试及两组计划控件事件见 [面板计划](面板周期计划.md)；最新托盘基线299项及另外四组控件事件见 [托盘报告](托盘与退出.md)。美化及安装包尚未实现，阶段三未整体完成。

## 方法与结论

结论：`PASS WITH NOTES`。六组隔离测试均通过；Release 0 警告/0 错误，公开行为回归 276/276 成功、0 跳过。

控件测试在独立进程的 STA 消息循环中实例化正式 `MainForm`，通过文本、选项和按钮事件检查界面接线。HTTP 固定使用进程内 mock；凭据和运行记录使用新建测试目录，保存的只有指定虚拟凭据。这些测试没有读取真实账户 key 或发送真实请求。

六组测试包含 70 次内部检查（包含按钮可用性和窗体关闭检查），不计入上述 276 项公开测试数量。控件驱动程序和原始结果保留在本机忽略的诊断目录，尚未纳入公开回归套件。它们验证真实控件事件，不能代替外部鼠标/键盘输入、屏幕视觉或安装版验收。

## 已验证行为

| 场景 | 结果 |
| --- | --- |
| 输入、模型、比例、保存 | key 控件可见且启用密码遮蔽；改 key 清空模型并禁用开始；错误虚拟 key 校验失败；四档目标正确，0%/非活动模型不能开始；保存不请求，普通配置无 key |
| 开始、暂停、继续、停止 | 运行时禁用重复开始和配置输入；暂停收齐在途后稳定，继续后用量重新增长；停止收齐后不自动重启 |
| 最小化 | 六组测试中运行时最小化仍有进展，暂停等待30秒稳定；后续独立诊断补10秒运行与300.007秒暂停最小化，请求、用量和运行记录不变，恢复继续/停止/正常退出通过 |
| 保存重开与仅本次 | 恢复虚拟密文、50%/2.5h 配置；记录确认不调用 API，连接需重新校验；仅本次选择下重开 key 为空，旧测试密文保留 |
| 运行期间退出与未知恢复 | 退出事件等待收尾，最终在途为 0；取消造成的未知记录保留，重开需要核查勾选，确认不发送请求或清除证据 |
| 429 保护 | 限流时不能普通继续，先停止收尾，再勾选核查确认；确认不自动开始 |

六个窗体场景均产生关闭事件，测试进程正常退出码为 0。历史测试中的 `Form.Close()` 覆盖当时的退出处理器，尚未覆盖通过鼠标点击标题栏关闭；当前标题栏关闭与最小化已改为托盘隐藏，明确退出的后续验证见托盘报告，不能将历史退出语义当作当前行为。另有用户手动保存和开始/暂停的反馈，与隔离日志一致。

后续较长诊断另外记录UI心跳、异常事件与外部进程存活。内部/外部退出码均为0，本次未复现原进程消失；不是原退出问题的修复，且不计入六组/70检查或276项测试。细节见 [最小化与退出诊断](最小化与退出诊断.md)。

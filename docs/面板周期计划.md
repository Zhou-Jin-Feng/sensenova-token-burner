# 面板周期计划

更新：2026-10-06。计划开关、间隔、下次运行时间和重开提示已接入WinForms，复用原有持久运行与周期调度。后续已接入 [托盘与退出](托盘与退出.md)，阶段三整体与安装包仍未完成。

## 使用方式

填写key，校验连接并选择活动模型、比例和间隔，然后勾选“启用周期计划（立即开始首轮）”。默认95%目标仍为1.2亿tokens，间隔默认5小时；启用前会保存配置，并按所选方式处理凭据。仅本次使用不会写新密文。0%、未校验连接、未确认运行记录、模型能力不足或无效间隔不能启用。

| 操作 | 面板行为 |
| --- | --- |
| 启用计划 | 准备输入后立即首轮，按启用时刻的UTC锚点安排下一轮；准备期间可通过“停止本轮”取消 |
| 查看计划 | 展示启用/关闭/保护状态、已开始轮数、跳过次数和下次本地运行时间；不是官方额度刷新倒计时 |
| 当前轮运行或暂停 | 配置输入锁定；暂停后不会另开一轮，错过周期跳过且不补跑 |
| 轮间修改比例或间隔 | 输入框允许编辑，点击保存后才更新未来计划；当前轮快照保持原目标，改间隔按原锚点重算未来边界，不立即运行 |
| 轮间保存0% | 关闭未来计划，不把0解释为无限运行；不会自动新开一轮 |
| 关闭计划开关 | 取消后续周期并清空下次时间；当前轮按原目标继续，需要时单独暂停或停止 |
| 停止本轮 | 停止新增并收尾，计划保持启用；未知用量或其他保护仍会关闭未来计划 |
| 修改key/保存方式或重新校验 | 先关闭计划并等当前轮结束；计划期间不能更换被运行使用的凭据或执行额外短探针 |
| 重新打开程序 | 显示已保存计划，开关保持关闭，不续跑旧目标；确认记录、重新校验连接后，由用户显式启用新计划 |
| 关闭或最小化窗口 | 隐藏到托盘，当前轮与已启用计划继续 |
| 面板或托盘“退出” | 关闭计划并收尾退出；真正退出后不会按时运行 |

例如08:00启用、间隔5小时，首轮立即开始；13:00、18:00为后续边界。如果13:00仍处于运行或暂停，跳过该次并等待18:00。重开后手动启用会建立新的锚点，不补之前漏掉的轮次。系统时钟与休眠规则见 [周期调度](周期调度与时间规则.md)。

## 保护与等待开销

计划使用同一PersistentRunSession、引擎、运行记录和请求执行器。每次请求仍先保存预留；未知用量、限流、认证/模型/参数错误、预算估计超限或记录写失败阻止后续计划。核查确认不发送请求，也不自动恢复计划；写失败不能靠改key或重新校验绕过。

输入在每次启用时准备并在该计划内复用，不每轮重复生成。没有新增服务、产品进程或依赖。底层调度仍使用异步等待，界面运行时每500ms观察快照、轮间每5秒读内存；仅状态变化才批量更新控件，保存、启停和运行控制可提前唤醒。轮间观察不执行API、凭据加载或状态保存。

计划子步骤最初只有短时行为证据，后续托盘子步骤已另用普通可见窗体复测完整负载、20条历史落盘和窗口/托盘等待，见 [资源报告](资源基线测量.md)。透明控件诊断窗体与外部采样进程不作为产品资源指标；五小时配置的短等待不等于完整等待五小时。

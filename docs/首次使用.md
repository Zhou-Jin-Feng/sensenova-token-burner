# SenseNova Token Burner 首次使用

适用多 key 版本、Windows 11 x64。Setup 自带 .NET 运行时，无需 SDK、Python 或 Codex，安装到当前 Windows 用户。

## 面板一览

- 顶栏：模拟环境/官方 API 标记、深浅色切换、设置。
- 状态条：本轮已确认合计、运行中/暂停/待核查数量、在途请求（圆点表示共享并发槽位）、下一次定时。
- 左侧 API key 列表：每行显示状态、用量条（实色为已确认，斜纹为在途预留）、已确认/目标和百分比。勾选框决定批量操作范围；点击一行在右侧查看详情。
- 右侧详情：标题旁是单个任务的“验证连接”“运行/继续”“暂停”“重置”，下面分四页——概览（燃烧仪表、本周专属额度进度、速率、预计完成、每分钟确认量）、目标设置、定时（含周额度与自动停止）、运行记录。
- 底部：最近一条提示；“动态”列出本次打开后的全部操作结果。

正在消耗 token 的任务用余烬橙色标出（状态、用量条、仪表和托盘图标）；其他状态不用这个颜色。

## 第一次运行

1. 点“添加 key”，粘贴 API key；名称和额度组选填（未填名称自动命名为 key-N）。key 按当前 Windows 用户用 DPAPI 加密保存，界面和日志不显示明文。保存不会开始运行。
2. 建议先点“验证连接”：只读取官方模型列表，检查 key 和活动模型；不发送生成请求、不构造长文本，也不查询余额或额度。
3. 在“目标设置”页选择比例（0–95%，25/50/75/95% 预设）或打开“使用自定义 tokens 目标”，点“保存设置”。95% 对应 1.2 亿，50% 对应 6000 万，0% 不消耗。有未保存的修改时页面会标出；此时运行、启用定时或切换到其他 key 都会先询问“保存并继续 / 放弃修改 / 取消”，运行和定时始终使用已保存的设置。修改从下一轮生效，继续当前轮仍用原目标。
4. 点“运行/继续”。联网前会弹出确认：本轮目标、已确认、剩余、额度组，以及每笔请求的规模——约 34 万字符程序合成输入、输出上限 1,024 tokens、本地预留约 241,024 tokens（不是实际 usage 或费用上限），和滚动额度提示。取消则不发任何请求。完成一个目标通常需要多笔请求。
5. 多个 key：在列表勾选后用列表上方的“运行/继续”“暂停”“重置”批量操作（只作用于已勾选且启用的 key）。批量运行同样先确认，按额度组汇总目标。

额度组填你自己起的账户名称（如“账户A”），同一账户的多个 key 填相同名称。它不是官方 ID，不创建或增加积分池，只用于汇总目标与风险；未分组也不表示独立额度。

## 暂停、继续与重置

- “暂停”停止新增请求，保留本轮进度，已发出的请求仍会结算；之后点“运行/继续”接着跑。
- 中断或重开后，“运行/继续”沿用原目标和已确认用量，继续剩余部分。
- “重置”确认后先结束运行和定时，把本轮记录归档到“运行记录”，客户端进度归零；不会自动运行。之后再点“运行/继续”才按已保存目标从 0 开始。
- 暂停和重置都会关闭未来定时，继续不会重新启用定时。重置只改变客户端进度，不退还已消耗积分，也不刷新官方额度。

例：目标 1.2 亿、已确认 6000 万时，“运行/继续”接着跑剩余 6000 万。如果已核查额度可以开始新一轮，先“重置”再“运行/继续”，才会从 0 跑完整 1.2 亿。客户端不会判断账户是否已恢复足够额度。

## 定时（可选）

不需要自动重复就不用设置。需要时在“定时”页填写间隔（默认 5 小时），也可配置周额度刷新周期（默认每周一 00:00，上限 60 万分，超额时自动跳过定时并于刷新后恢复），点“启用定时”：确认后立即开始第一轮，之后按开始时间每隔设定时间自动开始新一轮；上一轮未结束或错过的周期不补跑。“关闭定时”只取消未来触发，不中断当前轮。定时已启用时可直接修改间隔并点“保存间隔”。关闭应用后定时不会继续，重开需手动再次启用。5 小时只是客户端计划间隔，官方额度按滚动窗口计算，不是整点重置。

## 并发

在“设置”里调整，需先暂停全部任务并关闭定时：

- 全应用同时请求上限：1–10，默认 3，所有 key 共享。
- 单个 key 同时请求上限：1–10，默认 3。单个 key 并发过高容易触发限流；按现有保护，限流会让任务停下等待核查，效率反而下降。

同一个 key 不会被两个任务同时使用；一个任务出错时其他任务继续。

## 请求结果未知时

有请求没有拿到用量结果时，任务显示“待核查”，概览页出现提示。请先到 SenseNova 控制台核查实际用量和剩余额度，再勾选“我已核查官方用量和剩余额度，接受未知记录”，然后继续或重置。确认本身不发请求，也不会重发那些请求；无法确认时保留记录、不自动重发。记录损坏时保留原文件并阻止该任务继续消耗。

## 窗口、托盘与退出

最小化留在任务栏；标题栏 × 把面板收进托盘（第一次会有提示），任务和定时继续运行。左键单击托盘图标打开面板，右键可“暂停全部任务”或“退出”。“退出”才会关闭全部定时并收尾。面板隐藏或最小化时，任务完成或需要处理会发系统通知（是否弹出受 Windows 通知设置影响）。没有开机自启，重开不自动请求或消耗。

外观可在顶栏一键切换深浅色，或在“设置”里选择跟随系统。

## 积分与验证边界

1.2 亿 tokens/约 58,000 点为特定条件下的经验估计。高于目标可能扣通用积分，低于可能未用满专属积分；任何目标都不能保证绝对安全或精确返赠。请核查官方剩余额度及外部用量；客户端不读取账号密码，也不查询积分余额。

连接验证只确认模型列表 GET 和活动模型权限，不代表积分余额、额度或返赠得到确认。本项目曾用授权 key 完成一次受控的 34 万字符真实生成链路（1 GET + 1 POST，实际总 usage 218,781 tokens）；这不代表你的账户余额、扣减来源或返赠结果，也不替代你自己的首次小目标验证。确认内容中的历史 usage 仅为样本。

## 升级、数据与安装包

可在“设置”页面直接点击“检查更新”，自动拉取最新 Release 安装包并进行 SHA-256 核验后一键升级；也可手动下载安装包覆盖升级。升级前从旧面板或托盘正常“退出”，再安装。升级和卸载保留 `%LOCALAPPDATA%\SenseNova.TokenBurner\User` 下的配置、密文和历史（主题偏好在同目录的 `ui-preferences.json`）。旧单 key 沿用原路径，新任务使用独立子目录；共享电脑不要交换数据目录。新版本写入的配置旧版本可能无法读取，降级前请保留备份。

# SenseNova Token Burner 首次使用

适用Windows 11 x64。下载Setup.exe后双击安装，自带.NET运行时，无需SDK、Python或Codex。安装到当前Windows用户，不需要管理员权限。

1. 打开面板，填写自己的SenseNova API key。官方地址已预填，默认按当前Windows用户加密保存；也可取消保存，仅本次使用。
2. 点击“校验连接并读取模型”，选择活动Flash-Lite模型。
3. 选择预计消耗比例，点击“开始本轮”。默认95%对应1.2亿tokens，50%对应6000万；0%不运行。
4. 需要周期运行时，设置小时数并启用周期计划，默认5小时；启用会立即开始首轮。

关闭或最小化窗口后继续在托盘运行；双击托盘图标恢复。托盘可停止本轮或关闭未来计划，二者分开；选择“退出”才结束程序。没有开机自启，重开需要确认运行记录、重新校验并手动开始或启用计划。

比例是经验估计，不能保证任意起始余额下都只使用专属积分。请先核查官方账户余额；实际扣减来源和返赠以SenseNova账户记录为准。客户端不读取账号密码，不查询积分余额。

卸载不会删除用户数据。配置及加密key保存在`%LOCALAPPDATA%\SenseNova.TokenBurner\User`；共享电脑不要交换该目录。退出或网络取消可能留下未知用量，重开提示核查时先检查官方账户再确认。

预览安装包尚未签名，Windows可能显示来源或SmartScreen提示；核对下载来源与随包SHA256SUMS.txt，不需要关闭系统防护。当前已验证mock运行和托盘；真实账户扣减/返赠、完整无SDK机器安装仍待验证。普通窗口等待曾测得约102MiB，托盘等待约96MiB。

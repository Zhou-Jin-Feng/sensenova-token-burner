# SenseNova Token Burner 首次使用

适用新版多 key MVP、Windows 11 x64。Setup自带.NET运行时，无需SDK、Python或Codex，安装到当前Windows用户。

1. 填API key，可选备注如key-1、key-2，点击“添加并加密保存”。未填备注自动命名，可继续添加其他key；保存不运行。DPAPI按当前Windows用户加密，列表遮蔽。
2. 选择任务，设置独立0–95%比例或自定义tokens目标、启用状态、间隔（默认5小时），点击“保存所选设置”。95%为1.2亿，50%为6000万，0%不消耗。
3. 同账户的key填相同额度组。多key不意味着多份独立积分池，未分组也不表示独立额度。
4. 点击“运行所选”，或“运行全部”并查看各组目标合计与风险。地址和Flash-Lite活动模型固定；启动时自动校验模型权限，再发消耗请求。全应用最多3笔在途，一个任务错误时其他任务继续。
5. 单独或全部暂停、继续、停止；暂停/停止等待已发送请求结算。停止同时关闭未来计划，“关闭所选计划”只关闭未来触发。配置变更用于下一轮，不改当前目标。
6. 定时运行需显式“启用所选计划”，立即开始首轮，按开始时间锚定。上一轮未结束或错过周期不连续补跑；5小时仅为客户端计划，官方额度为滚动窗口，不是整点重置。

列表展示确认tokens、目标、状态、错误/待核查及下次计划；运行全部有整体进度和收尾汇总。完成提示在左下角；隐藏时调用系统托盘通知，实际弹出受Windows通知设置影响。

关闭或最小化进入托盘，任务与计划继续；双击图标恢复。“退出”关闭全部计划并收尾。没有开机自启，重开不自动请求或消耗。

未完成任务可“继续剩余目标”，沿用原目标及已确认tokens。未知请求先核查官方用量/额度，再勾选确认；确认不发送请求，也不恢复服务端正在生成的同一请求。新的未知结果需再次核查，记录损坏时保留原文件并阻止该任务消耗。

1.2亿tokens/约58,000点为特定条件的经验估计。高于目标可能扣通用积分，低于可能未用满专属积分；任何目标都不能保证绝对安全或精确返赠。请核查官方剩余及外部用量，客户端不读取账号密码、不查询积分余额。

升级前从旧面板/托盘正常“退出”，再安装。升级/卸载保留`%LOCALAPPDATA%\SenseNova.TokenBurner\User`的配置、密文和历史。旧单key沿用原路径，新任务独立子目录；共享电脑不要交换数据目录。

安装包未签名，核对下载来源及随包SHA256SUMS.txt。新版模拟验收通过；新版真实key/积分消耗、实际升级及无SDK新系统仍未验证。

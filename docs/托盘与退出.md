# 托盘与退出

更新：2026-10-06。WinForms已接入原生托盘，复用当前窗体、持久运行会话与周期计划。没有新增产品进程、后台服务、轮询定时器或运行依赖；阶段三整体与安装版尚未完成。

## 使用方式

| 操作 | 行为 |
| --- | --- |
| 点击标题栏关闭或最小化 | 隐藏到托盘；当前轮与已启用计划继续，不销毁窗体或重新开始 |
| 双击托盘或选择“显示面板” | 恢复同一个窗体及原普通/最大化状态，同步隐藏期间的配置与运行状态 |
| 查看托盘状态 | 显示运行、暂停、等待计划或计划关闭；收尾时显示正在退出 |
| 选择“停止本轮” | 停止新增请求并处理在途结果；不会单独关闭未来计划 |
| 选择“关闭未来计划” | 取消后续周期；当前轮继续，需要时另行停止 |
| 点击面板或托盘“退出” | 关闭计划、取消或收尾当前操作，保存运行证据，再关闭窗体并释放托盘组件 |

托盘图标可能位于Windows通知区域的隐藏图标菜单。首版使用系统图标，品牌图标与布局留美化子步骤。程序没有开机自启或独立服务；真正退出后不会按时运行，重新打开仍需确认记录、校验连接并显式启用计划。

停止或退出不能证明服务端未消耗。有效usage按已有引擎规则结算，未能确认的用量保留为未知，重开需核查；详见 [运行恢复](运行记录与人工恢复.md)。系统关闭会话等非用户关闭原因进入退出收尾，不转为隐藏；实际Windows关机和休眠尚未验证。

## 实现与验证

隐藏时仅同步托盘状态，显示时更新全部控件；tooltip只在内容变化时赋值，恢复不创建新运行会话。VM仍按运行500ms/轮间5秒观察内存快照，仅变化时通知。没有为托盘新增API读取、状态保存或定时器。

Release构建0警告/0错误，299/299公开测试成功、0跳过（计划基线292项，新增7项）。`tests/SenseNova.TokenBurner.Tests/TrayWindowTests.cs`使用正式窗体与STA消息循环覆盖关闭隐藏、隐藏配置恢复、最大化后最小化恢复、重复显示/隐藏、菜单退出与图标释放。WindowsShutDown及ApplicationExitCall只向隔离窗体合成事件，没有关闭Windows。

独立控件探针完成四组场景、36次内部检查，未计入299项公开测试：

- 隐藏运行仍增长；菜单关闭计划后原轮继续，菜单停止后隐藏状态收尾并解锁；重复显示/隐藏不发新请求。
- 首轮完成后隐藏等待10秒，计划保持启用，请求数和记录SHA-256不变；等待菜单与停止项状态正确，恢复完整同步；菜单正常退出。
- 隐藏运行中直接退出，禁用托盘操作；落盘计划关闭、0在途，本次3笔在途成功结算，没有未知用量。探针最初强制要求未知用量的假设有误，已改为检查实际结算证据，没有为此改产品规则。
- 重开读取证据等待确认，0自动请求/计划关闭；确认保留原用量，不自动开始。

四个窗体均产生FormClosed，内部与外部进程退出码均为0，最终磁盘记录0在途；已退出VM不再刷新面板快照，活动退出应核对最终落盘，不能把旧UI快照当最终结算。使用固定虚拟key、新隔离目录和终端HTTPmock，透明测试窗体没有驱动原生鼠标/键盘或验证像素。普通窗体恢复回归和资源另用不透明窗体，方法与数据见 [资源报告](资源基线测量.md)。

本机最终控件证据保存在忽略目录 `.local/verification/ui-acceptance-20261006/tray/run-7f20a72e68a44635ae6dba596303249f/`，外部退出记录为 `.local/verification/tray-external-exit.json`；早先两组/25检查和失败假设的报告保留，不含真实key、请求正文或响应。

普通窗体资源首测发现：最小化隐藏后先设WindowState再Show，Show仍会带回原生最小化状态。已改为Show后恢复目标状态；普通窗体回归先失败（Normal/Minimized不符）后通过，并覆盖普通及最大化两种状态。透明窗体测试不能替代这个原生placement路径。此问题与先前原隔离进程消失不是同一个现象。
